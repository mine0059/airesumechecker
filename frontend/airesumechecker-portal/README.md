# AI Resume Checker — Frontend

React + Vite + Tailwind CSS frontend for the AI Resume Checker platform.

> **This is part of a monorepo.** See the [root README](../../README.md) for full setup instructions, API reference, and project overview.

## Quick Start

```bash
npm install
npm run dev
```

Runs on **http://localhost:5173**. All `/api` requests are proxied to the backend at `http://localhost:5000` (configured in `vite.config.js`).

## Stack

- **React 18** — UI framework
- **Vite** — build tool and dev server
- **Tailwind CSS v4** — utility-first styling
- **Axios** — HTTP client
- **React Router** — client-side routing
